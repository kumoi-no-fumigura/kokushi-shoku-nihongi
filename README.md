## 作品について

六国史の第二。文武天皇から桓武天皇の延暦10年までを漢文の編年体で記す。宣命を多く収めることでも知られる。ここの本文は『国史大系』の活字本により、巻末に撰進の上表文などを添える。

## 底本

- [国史大系 第2巻 続日本紀](https://dl.ndl.go.jp/pid/991092)（経済雑誌社 編・国史大系・経済雑誌社・1897年・p6-400）

国立国会図書館デジタルコレクションの「インターネット公開（保護期間満了）」の資料です。

## 本文の作り方

国立国会図書館の全文テキスト（OCR）から作品の範囲を切り出し、原本のページごとに段落に分け、ページの先頭や末尾にある書名（柱）を除きました。それ以外は手を加えていません。旧字の誤認識・ルビ・割注などがそのまま混じっています。

## 誤りを見つけたら
